# 00: 環境と観測の確認

## 目的

robosuiteの標準Lift環境をPandaロボットで起動し、VLAに渡す観測と、環境に渡す行動の意味を理解します。

## 実行方法

[Colabノートブック](../../colab.ipynb)のセットアップ後、「00: 環境と観測を確認する」のセルを実行します。
画像・動画・環境の仕様がノートブック内に表示されます。

開発者がコマンドから実行する場合は、プロジェクトのルートで次を使います。

```bash
vla-inspect --config configs/lift.json --max-steps 20
```

ディレクトリ順にスクリプトを見る場合も、入口は同じ処理を呼びます。

```bash
python lessons/00_environment/run.py --config configs/lift.json --max-steps 20
```

姿勢の移動指令をゼロにし、グリッパーを開いた状態で環境を進めます。学習モデルは読み込みません。
結果は`outputs/<日時>_inspect_<ID>/`に保存されます。

環境生成と観測・行動の変換は`src/vla_workshop/envs/`にまとめ、01の推論や後のデータ収集・評価でも共通で使います。

## 確認すること

- カメラ画像の名前、解像度、色順、上下方向。
- ロボット状態の各要素、形状、単位。
- コントローラの設定と、行動の各要素・範囲・座標系・制御周期。
- モデルに渡す観測と、評価のためだけに使う正解情報の区別。

`episode_000/`の画像と`video.mp4`を開いて、ロボットと立方体が写っていることを確認します。
`environment.json`でコントローラ設定、`steps.jsonl`で8次元状態と7次元行動を確認してください。
`initial_observation.npz`には初期観測とシミュレータ状態が入り、`model.xml`にはモデル定義が入ります。

EGLの初期化に失敗する場合は、NVIDIAドライバとLinux側のEGL/OpenGLライブラリを確認してください。
CUDAの推論と描画の問題を切り分けるため、まずこの実習が通ることを確認します。
