# 01: SmolVLAの推論

## 目的

画像・ロボット状態・言語指示からSmolVLAで行動を推論し、robosuiteで実行する一連の流れを作ります。

## 実行方法

[00の実習](../00_environment/README.md)が通ったら、[Colabノートブック](colab.ipynb)を開き、準備から順番に実行します。前の冊の実行状態は不要です。
動画と結果、実際のCUDAデバイス情報がノートブック内に表示されます。

開発者がコマンドから実行する場合は、同じプロジェクトのルートで次を使います。

```bash
vla-rollout --config configs/lift.json --max-steps 20
```

同じ入口を実習フォルダから見る場合は、次のコマンドでも実行できます。

```bash
python lessons/01_smolvla_inference/run.py --config configs/lift.json --max-steps 20
```

初回は固定したrevisionのLIBERO用SmolVLAモデルと、VLMの設定・トークナイザーをダウンロードします。
モデル付属のpreprocessor/postprocessorを使い、状態の正規化と行動の逆正規化を行います。
CUDAが使えない場合や入出力の次元が一致しない場合は、エラーで停止します。

00と同じ共通の環境生成・観測取得・行動実行の処理に、SmolVLAの推論を接続します。
環境コードをこの実習用に複製せず、学習後の評価でも同じ接続を使います。

## 確認すること

- 使用モデルとバージョン、期待する画像・状態・行動の仕様。
- 観測の前処理と行動の後処理、正規化・逆正規化。
- 行動の次元だけでなく、各要素の意味・単位・座標系の対応。
- action chunkから実行するステップ数と、再推論のタイミング。
- エピソードをまたぐモデル内部状態のリセット。

結果は`outputs/<日時>_smolvla_<ID>/`に保存されます。
`run.json`でCUDAデバイス・モデルのsnapshot・推論設定・パッケージのバージョンを確認してください。
`episode_000/steps.jsonl`には各stepの状態、逆正規化後の行動、clip後の環境入力、終了判定が入ります。
`video.mp4`と`summary.json`を確認し、正常終了したか、実際にどのような動きだったかを説明してください。

20ステップの確認後は`--max-steps`を外して200ステップ、`--episodes 3`を加えて複数エピソードを試せます。
実行はシミュレーション時間と同期しません。推論が遅い場合は壁時計上の時間が長くなります。

## 達成条件

観測取得 → 推論 → 行動実行を繰り返し、終了条件またはステップ上限で停止できること。
動画と、実行条件・入出力・終了理由を確認できるログを保存できること。

この段階ではタスク成功を必須にしません。接続の正しさを確認し、タスクの成否は別に記録します。
