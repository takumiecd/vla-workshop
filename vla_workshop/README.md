# VLA Workshop

robosuiteでSmolVLAを動かし、最後はLIBEROでの成功率改善に取り組む実習です。
教材は回ごとのディレクトリにまとめ、準備できた回から1回ずつ公開します。

```text

├── README.md
├── 00_environment/

├── 01_smolvla_inference/
│   └── 01_smolvla_inference.ipynb
└── _dev/                         # 教材を更新するための共通コード
```

現在、配布するのは各回のipynbだけです。実習コードは同梱し、ライブラリとモデルは実行時に取得します。

## 全体の予定

未公開の回は実装・確認後にディレクトリと実行リンクを追加します。日程は別途案内します。
各回は「目的 → 準備 → 設定 → 実行 → 結果確認 → 考察・保存」の順にそろえます。

### 00・01：まず環境とモデルを接続する

標準のrobosuite Lift/Pandaを使います。00では画像・状態・行動の意味を理解し、01では共通の環境にSmolVLAを接続します。
提出するものは、短い実行動画、ログ、確認課題への回答です。ここでの成否はLIBEROの成功率ではありません。

### 02：LIBEROで評価の基準を作る

共通チェックポイント、対象タスク、評価用初期状態、seed、試行数、推論条件を固定します。
提出するものは、タスク別の成功率、実行条件、代表的な成功・失敗動画です。
この評価手順を04・06・07でも使い、Liftの結果と混ぜません。

### 03：学習に使うデータを理解する

小規模なLIBERO由来のLeRobot形式データを題材に、エピソードの再生、入出力の対応、成功・失敗、欠損や長さを確認します。
学習用・検証用をエピソード単位で分け、最終評価条件と区別します。
提出するものは、データの確認結果と、使用するデータの版・分割の記録です。

### 04：既存データで学習を一度通す

03で確認した共通データから、短いfine-tuningを実行します。
最初はVLMを固定し、行動を出すexpertと状態の射影部分を学習する構成を予定しています。
T4で動くバッチサイズ・学習量・メモリ使用量を実装時に検証してから配布します。
提出するものは、学習設定、学習曲線、チェックポイントの保存先、02と同じ条件での学習前後の評価です。

### 05：データを収集し、学習に使えるか確認する

開始・終了・中断を扱い、画像・状態・行動・指示・終了状態をエピソード単位で保存します。
再生して採否を確認し、03と同じ形式へ変換します。失敗データも区別して記録します。
提出するものは、収集条件、採用・不採用の内訳、再生動画、変換済みデータの保存先です。

Colabでは記録の確認と再生を扱います。手動収集の入力方法は、ブラウザUIまたはローカル入力装置との接続を実装時に検証します。
ノートブックの通常のキー入力だけで連続的な操作ができることは前提にしません。

### 06：収集したデータで再学習する

04と同じ学習・評価の流れに、自分たちのデータを加えます。
データ数と学習量を記録し、既存データだけの場合と比較します。
提出するものは、使用エピソード一覧、学習条件、タスク別の比較結果、改善・悪化した例です。

### 07：改善を検証し、知見を共有する

データの選び方、量、学習条件、推論条件などから仮説を立て、まず一つずつ変更します。
条件に合う検証結果でモデルを選び、共通の最終評価条件で比較します。
提出するものは、ベースラインとの比較表、再実行できる設定・コード、代表動画、考察です。
成功率だけでなく、試行数、実行時間、データ量、失敗の傾向も共有します。

## ipynbとPythonファイルの使い分け

参加者の入口は全回ともipynbです。設定・実行・結果表示・考察をノートブックに置きます。
環境やモデルとの接続など共通処理は、必要な分を内蔵して自動準備します。

- **00・01**：ipynbだけを配布します。
- **02〜04・06**：変更する実験条件をJSONとして配り、ノートブックから読み込みます。
- **05・07**：長い記録処理や、参加者が編集する実験処理はPythonファイルとして配ります。

複数ファイルになる回は、その回のディレクトリを一式で配布します。
ipynbの冒頭に「今回必要なファイル」と配置場所を明示し、別々の場所から手で集める手順は作りません。
大きなデータセット・重み・動画はDriveやHugging Faceに置き、保存先と版を指定して読み込みます。
CLIを参加者の必須操作にはせず、実行はノートブックのセルから行います。

教材の更新用ファイルは[_dev/](./_dev/README.md)にまとめています。
T4への接続は参加者から確認報告があります。一連のGPU推論は未検証です。[検証状況](_dev/docs/validation.md)
